# RegencyLab

Banco de padrões de regência/collocations por termo e categoria. Cada card guarda forma gramatical, pattern, complement, exemplo/tradução, significado e contraste opcional.

## Fluxos

- Pasta `Regency Essentials` é catálogo inicial versionado.
- Criação assistida por IA ou formulário manual.
- O modo manual deve ser espaçoso e responsivo; opções incompatíveis de forma precisam ser desabilitadas sem contraste ilegível.
- Tags primárias são Verb, Adjective e Noun. Formas como base/past são subtags; novas tags visuais que cortem a palavra não devem ser adicionadas ao card.
- Busca, layout, mover/excluir, Study, Review e progresso por pasta seguem o padrão transversal.

## Study

Modos flip, recall e multiple choice. Distratores favorecem mesma família/termo e depois categoria; cloze pode usar pattern/exemplo. `Again` segue o mesmo limiar global e registra o primeiro erro mesmo se houver acerto posterior.

## IA

Pipeline gerador → fallback quando necessário → revisor estrito → sanitização/auditoria. Campos opcionais de exibição não devem apagar dados persistidos.
