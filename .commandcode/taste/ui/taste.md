# ui / visual-consistency
- Visual system (folder manager, cards, popups, study modes, search bars) must be identical and uniform across ALL labs (VocabLab, RegencyLab, RuleLab, ReadLab) — any pixel/behavioral divergence is a bug to fix, not a per-lab variant. Confidence: 0.9
- Card action icons (trash, edit, audio, translate) must remain hidden and only appear on hover over the card, to avoid visual pollution. Confidence: 0.85
- Scrollbars should be visually hidden/invisible throughout the app, while keeping scroll functional. Confidence: 0.8
- Card/folder tags must always stay on a single line (never wrap) and be the same size across all labs. Confidence: 0.8
- In dark mode, folder backgrounds should stay uniform (only the icon color varies); avoid strong/colorful themes and "color explosions" — keep the UI minimal and monochrome-ish. Confidence: 0.8
- Buttons/controls (e.g. "Study in N as M cards" pill) must match the height of sibling controls (e.g. the search bar); proportions should be consistent across the app. Confidence: 0.7
- Closable/confirmation popups (delete folder, transfer) must be the same size and format as the folder manager popup; the delete popup should overlay the manager for a clean look. Confidence: 0.75
- Study mode keyboard shortcuts (arrows: → I knew it, ← Again, ↑ reveal/flip, ↓ back to front) should be supported across all compatible study/review modes in all labs, and documented in the Wiki. Confidence: 0.8
- Mode selectors (Single/Batch/Manual or Single/Manual) belong below the input field as pills, styled consistently with VocabLab; toggling to a manual mode should expand smoothly without changing the outer card size. Confidence: 0.75
- Multiple Choice study should only be enabled when the session has enough real cards + distinct answers, using only real in-session cards as distractors (never AI-generated fake alternatives). Confidence: 0.75
