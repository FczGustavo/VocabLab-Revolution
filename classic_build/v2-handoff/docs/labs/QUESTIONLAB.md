# QuestionLab

## Comportamento confirmado

Usuário escolhe tópicos/subtópicos gramaticais e quantidade; IA gera questões originais de múltipla escolha A–E, exatamente uma correta, com explicações. Questões respondidas são registradas para reduzir repetição. Sessões geradas podem ser salvas em listas e organizadas em pastas.

Há dez famílias amplas: verbos; voz/modais; condicionais/reported speech; phrasal/preposições; substantivos/determinantes; pronomes/artigos; adjetivos/advérbios/ordem; conectores/estruturas; pontuação/ortografia; vocabulário.

Gerador e revisor são modelos separados. Conteúdo genérico/fraco/similar pode ser regenerado uma vez. Há integração opcional com palavras do VocabLab.

## Limites

QuestionLab tem quiz próprio; não participa do Review/Study Progress transversal. Cache compartilhado via Supabase existe, mas o limite auditado de uso do cache é zero, logo seu benefício atual é incerto.
